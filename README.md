# Agent pet library

Spritesheet assets for open-ai-canvas. Import manifest: `manifest.json`.

Each sheet uses 8 columns of 192 × 208 cells: v1 has 9 rows, v2 has 11 rows. SHA-256 identifies content and prevents duplicate imports.
